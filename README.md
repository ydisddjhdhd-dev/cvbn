# 🛠️ دليل التثبيت الإرشادي الكامل للغة `cmdg`

يحتوي هذا الدليل على الشرح المفصل لخطوات إعداد بيئة التشغيل، وتثبيت المتطلبات البرمجية، وحل المشاكل الشائعة لتشغيل المفسر الخاص باللغة.

## 📋 المتطلبات الأساسية (Prerequisites)
قبل البدء في عملية التثبيت، يرجى التأكد من توافر الأدوات التالية على نظام تشغيلك:
* **نظام التشغيل:** متوافق مع أنظمة Linux / Windows / macOS.
* **البيئة البرمجية:** مثبت لديك إصدار حديث من (Python 3.x أو Node.js) حسب بيئة بناء المفسر.
* **أداة إدارة الحزم:** (`pip` أو `npm`) لإدارة المكتبات البرمجية المشهورة المبنية عليها اللغة.

---

## 🚀 خطوات التثبيت بالتفصيل (Step-by-Step Installation)

### الخطوة الأولى: استنساخ مستودع الأكواد (Clone the Repository)
قم بفتح الطرفية (Terminal) أو موجه الأوامر (CMD)، ثم قم بجلب نسخة كاملة من أسطر الكود البرمجية للمشروع عبر الأمر:
```bash
git clone https://github.com
```
بعد اكتمال التحميل، انتقل مباشرة إلى مجلد المشروع الرئيسي:
```bash
cd cvbn
```

### الخطوة الثانية: تهيئة البيئة الافتراضية (اختياري ولكن موصى به)
لحماية مكتبات جهازك وضمان استقرار أسطر الأوامر، يفضل إنشاء بيئة معزولة للمشروع:
```bash
# لأنظمة لينكس وماك
python3 -m venv venv
source venv/bin/interact

# لأنظمة ويندوز
python -m venv venv
.\venv\Scripts\activate
```

### الخطوة الثالثة: تثبيت المكتبات والاعتماديات المشهورة (Dependencies)
تعتمد لغة `cmdg` على مكتبات برمجية شهيرة لتفسير الكود العربي. قم بتشغيل أمر التثبيت الشامل لجلب كافة الحزم المطلوبة دفعة واحدة:
```bash
pip install --upgrade -r requirements.txt
# أو إذا كان المشروع يعتمد على حزم مخصصة أخرى
npm install
```

---

## 💻 طريقة تشغيل واختبار اللغة (Running the Interpreter)

بعد إتمام كافة خطوات التثبيت الطويلة بنجاح، يمكنك الآن كتابة أول كود لك بامتداد اللغة وتشغيله عبر تمرير الملف إلى الملف التنفيذي الرئيسي:

```bash
# تشغيل المفسر واختبار كود مكتوب بالعربية
python main.py examples/hello_arabic.cmdg
```

## 🔍 استكشاف الأخطاء وإصلاحها (Troubleshooting)
* **خطأ عدم التعرف على الأوامر:** تأكد من إضافة `python` أو `npm` إلى متغيرات البيئة (PATH) الخاصة بنظامك.
* **مشكلة في ترميز الحروف العربية (UTF-8):** تأكد من أن الطرفية أو المحرر لديك يدعم ترميز خطوط اللغة العربية بالكامل لتقرأ الأكواد بشكل صحيح.
